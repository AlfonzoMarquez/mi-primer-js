
##  Contenido del Repositorio

- `conceptos/variables.js`: Declaración de variables (`let`, `const`), tipos de datos y cálculo dinámico de edad.
- `conceptos/condicionales.js`: Ejemplos de toma de decisiones (`if`, `else`) y funciones.
- `proyecto-final/`: Aplicación interactiva de un **Contador Dinámico** con manipulación del DOM y eventos de usuario.
